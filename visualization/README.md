# About this folder

This folder contains the files needed to create the figure in the original article. This folder contains the following files:

1. `visualization.R`: R code to create all the figures in the original article.

2. `results`: The folder contains all the numerical results (in the csv format).

NOTE: Due to GitHub’s file size limit, we cannot upload `ps_save.csv`, which is used to generate Figure 4 (the propensity score distribution plot). Please download this file from our [Dataverse repository](https://doi.org/10.7910/DVN/2DZQ6T) if needed.
